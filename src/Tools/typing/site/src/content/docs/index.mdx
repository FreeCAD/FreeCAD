# FreeCAD Python API

This site hosts generated API reference content from the curated Python stub
sources in the FreeCAD tree.

## Workflow

1. Regenerate the API reference with `npm run generate:api`.
2. Start the local docs preview with `npm run dev`.
3. Edit the source-adjacent stub files and rerun generation when the API docs
   need updates.
