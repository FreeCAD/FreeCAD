# FreeCAD API

This site hosts generated API reference content for FreeCAD's Python and C++
surfaces.

## Workflow

1. Regenerate the API reference with `npm run generate:api`.
2. Start the local docs preview with `npm run dev`.
3. Edit the source-adjacent Python stubs or the C++ docs extraction pipeline
   and rerun generation when the API docs need updates.

## Reference

- [Python API Overview](/python-api/)
- [C++ API Overview](/cpp-api/)

The `python-api/` and `cpp-api/` subtrees are generated. The landing page and
site configuration in this directory are maintained by hand.
