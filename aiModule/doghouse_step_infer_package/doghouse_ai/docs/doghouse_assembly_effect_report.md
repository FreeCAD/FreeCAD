## 算法路径

每个 doghouse 实例按以下顺序识别安装面和安装孔：

1. 先运行 VF2 拓扑规则路径。
2. VF2 只有在找到可靠解析孔时才被采用。
3. 可靠解析孔必须满足：
   - 孔组中存在 `cylinder` 或 `cone` 面；
   - 半径在 `2.0 ~ 6.0` 范围内；
   - 候选安装面为平面，面积在 `35 ~ 2000`；
   - 孔轮廓投影位于安装面内部；
   - AI 结构概率支持该结果，即安装面 `mount_prob >= 0.35` 或孔壁 `hole_wall_prob >= 0.35`。
4. 如果 VF2 不可靠，或者解析半径来自非安装圆柱，则转 AI 结构路径。
5. AI 结构路径使用 `mount_prob`、`hole_wall_prob`、外侧程度和邻接拓扑，不依赖解析半径。
6. 如果 VF2 和 AI 都失败，再使用本地 BREP 圆柱聚类兜底。

这次调整的关键点是：AI 不再只是“补孔”，而是作为结构语义门控参与规则路由。VF2 要想压过 AI，除了有解析半径，还必须得到 AI 结构概率支持。

### AI 结构示例：COMPOUND009 实例 1

结果：

- 安装面：`737`

- 方法：`ai_structure`

安装面 `737` 计算：

```text
mount_prob           = 0.996247
outer_support_margin = 0
area                 = 761.241

score =
20 * mount_prob
+ max(0, 8 - outer_support_margin)
+ min(area, 900) / 150

= 20 * 0.996247 + 8 + 761.241 / 150
= 19.92494 + 8 + 5.07494
= 32.99988
```

对比候选面 `744`：

```text
mount_prob           = 0.996536
outer_support_margin = 2.5
area                 = 779.155107

score =
20 * 0.996536 + max(0, 8 - 2.5) + 779.155107 / 150
= 19.93072 + 5.5 + 5.19437
= 30.62509
```

虽然 `744` 的 `mount_prob` 略高，但它不如 `737` 外侧，因此 `737` 胜出。

孔壁组件平均概率：

```text
mean_hole_wall_prob = 0.812691
confidence = 0.5 * 0.996247 + 0.5 * 0.812691 = 0.904469
```

置信度高于 `0.35`，所以该 AI 结构结果有效。

## 当前问题

安装面已经稳定，当前主要问题是安装孔 FP：

- AI 结构路径会把孔壁附近的过渡角、小连接面一起纳入孔壁组件。
- `COMPOUND009`、`未命名-1031001001-B121031101001-B001` 和 `未命名-6302001001-B126302301001-B12` 都是召回完整但 FP 偏多。
- `未命名-6302001001-B126302102001-B12` 还存在孔壁漏检，召回只有 `3/7`。

## 下一步建议

1. 在 AI 结构路径中增加孔壁组件收缩策略，只保留高 `hole_wall_prob` 主体面，降低过渡面 FP。
2. 对 `6302001001-B126302102001-B12` 单独检查 FN `[9, 10, 11, 12]` 的 `hole_wall_prob` 和邻接距离，判断是模型概率问题还是 hop 限制问题。
3. 对 AI 孔壁输出区分两类标签：`hole_wall_core` 和 `transition_wall`，用于后处理时保留真实孔壁、弱化过渡面。
